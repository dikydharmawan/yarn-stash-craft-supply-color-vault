# Koleksi Benang — Gudang Warna Perlengkapan Kerajinan

Aplikasi satu halaman untuk mengatalogkan benang & perlengkapan tekstil kerajinan secara lokal di browser.

## Fitur
- Tambah entri: nama bahan, warna (pemilih warna), berat/jenis, jumlah + satuan, merek, catatan
- Grid kartu dengan contoh warna sebagai daya tarik visual utama
- Hapus entri (dengan konfirmasi dua langkah)
- Filter kartu berdasarkan berat/jenis
- Persistensi `localStorage` — data tetap ada setelah penyegaran halaman

## Menjalankan
Buka `index.html` di browser mana pun. Tanpa dependensi, tanpa backend, tanpa API eksternal.
